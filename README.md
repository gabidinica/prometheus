# Prometheus Projects in Kubernetes

## 1. Install Prometheus Stack in Kubernetes
- Repository: [prometheus-in-kubernetes](https://github.com/gabidinica/prometheus/tree/main/prometheus-in-kubernetes)  
- Description: Deploy Prometheus, Alertmanager, and Grafana in a Kubernetes cluster using Helm.  

## 2. Configure Alerting for Our Application
- Repository: [alert-for-our-application](https://github.com/gabidinica/prometheus/tree/main/alert-for-our-application)  
- Description: Configure Prometheus and Alertmanager to send alerts when CPU usage is high or pods fail to start.  

## 3. Configure Monitoring for a Third-Party Application
- Repository: [monitor-for-third-party-app](https://github.com/gabidinica/prometheus/tree/main/monitor-for-third-party-app)  
- Description: Monitor Redis using Prometheus Exporter, configure alert rules, and visualize metrics in Grafana.  

## 4. Configure Monitoring for Own Application
- Repository: [monitor-own-app](https://github.com/gabidinica/prometheus/tree/main/monitor-own-app)  
- Description: Monitor a Node.js application by exposing metrics via Prometheus client library and visualize them in Grafana dashboards.
